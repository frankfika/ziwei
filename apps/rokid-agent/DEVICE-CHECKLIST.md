## 2. 分组步骤

### A 开机与首启

**目标**：从「戴上眼镜」到「看见一张十二宫盘面」，全程不白屏，并且**端侧引擎真的在跑**。

| 步 | 操作 | 观察点 |
|---|---|---|
| A1 | 手机 Rokid Ai APP → 「设置 → 开发者 → 更新眼镜资源包」 | 提示「**智能体资源包下载成功**」 |
| A2 | 戴上眼镜，说「**打开紫微星盘**」（语义命中进入） | HUD 亮起 |
| A3 | **计时**：从说完话到出盘 | 目标 **≤ 3 秒**（端侧排盘不依赖网络；慢了先查是不是走了服务端兜底） |
| A4 | 数格子 | **12 个宫格**（4×4，中宫 240×176 空着），不是 11、不是 13 |
| A5 | 看中宫末行（第 9 行） | 应为「**端侧计算**」。若显示「服务端计算」→ 端侧引擎没加载，见 §3 第 1/2 条 |
| A6 | 看中宫末行第 8 行（状态行） | 传感器标签三选一：「头部准星」/「抬头选宫」/「镜腿选宫」。**记下是哪一个**，D 组要用 |
| A7 | 看中宫最后一行（第 10 行，仅示例盘时才有） | **首次安装（无本机存档）应该有**「示例盘　返回键换成你的生辰」；如果之前录过生辰，会直接读本机存档（`ziwei.agent.profiles`），就**没有**这行 |
| A8 | 看选中格 | 首启应落在**命宫**（`mingGongBranch`），中宫「选中宫」行显示「命宫」 |
| A9 | 看层标题 | 应为「**本命盘**」 |

**通过标准**
- 出盘，无白屏、无黑屏、无残缺渲染
- 12 宫齐全，中宫各行文字不溢出
- 中宫第 8 行状态行有传感器标签 + 「端侧计算」
- 首启 3 秒内出盘

**不通过怎么办**：白屏/黑屏 → §3 第 1、2 条；出盘慢或显示「服务端计算」 → §3 第 1 条；宫格数不对 → §3 第 20 条（引擎指纹不对，重新打包）。

### B 语音录入生辰

**目标**：说一句话 → 正确解析 → **替换掉示例盘**；以及**说错时优雅失败**。

| 步 | 操作 | 观察点 |
|---|---|---|
| B1 | 在盘面态按【**返回**】键 | 应进入「说出你的生辰」浮层（**不是退出应用**）。这是盘面态唯一的重录入口 |
| B2 | 按【**确认**】键 | 浮层提示变「**在听……请说出你的生辰**」 |
| B3 | 说「**1990年1月1日 早上 男**」 | 识别窗口 8 秒（`LISTEN_TIMEOUT = 8000`） |
| B4 | 看浮层中间那行 | 应回显识别原文（`heardText`），不是空 |
| B5 | 看盘面 | **录入浮层必须已经关掉**（能直接看到盘面），且中宫末行的「示例盘…」那行**消失**。⚠️ 若浮层还盖着盘面 ⇒ 说明解析成功后没关浮层，用户按返回键会直接退出应用（2026-11-08 已修，见 §3 第 20 条） |
| B6 | 换成第二种说法测一遍：先按【返回】回录入层，再按【确认】，说「**我是一九九零年一月一日生的，晚上十一点，女**」 | 应同样成功（口语文本解析覆盖中文数字年份 + 口语时段） |
| B7 | **故意失败**：再说一次确认键，然后说「**今天天气不错**」 | 应提示「**没听清出生日期，再说一次：1990年1月1日 早上 男**」，**不白屏、不退出、不报错** |
| B8 | 说一句含二十九号的：「2000年2月29号 丑时」 | 应成功解析（闰日/越界回退逻辑） |
| B9 | **故意不说时辰**：说「**1990年1月1日 我不知道时辰 男**」 | 应**成功出盘**，盘面末行出现「**时辰按午时估算**」（时辰序号 6 = 午时），浮层同样关掉。⚠️ 解析不出来 = 回归了 |
| B10 | 退出应用再进 | 应直接读本机存档的盘（`ziwei.agent.profiles`），**不再显示示例盘**；若那张盘是估算来的，末行仍应显示「时辰按午时估算」 |

**通过标准**
- 三种说法（B3 / B6 / B8）都能解析出年月日 + 时辰 + 性别并成功换盘
- **B3/B6/B8/B9 四种说法说完后，录入浮层都要自动关掉，用户直接看到盘面**
- **缺时辰（B9）不失败，按午时兜底并在盘面上明示「时辰按午时估算」**
- 识别耗时 ≤ 8 秒，回显文本非空
- 失败路径（B7）只提示，界面不崩、不白屏
- 退出重进后不再出现示例盘标注（说明存档写进去了）

**不通过怎么办**：完全没反应/没声 → §3 第 14 条；能识别但解析不出 → §3 第 14 条后半（先确认说的是「年月日 + 时辰」三件套）；示例盘标注没消失 → §3 第 19 条。

### C 盘面渲染与可读性

**目标**：**120×88 的格子里字不截断**，运限层小标不挤爆格子，中宫 176px 高度塞得下 9 行。

| 步 | 操作 | 观察点 |
|---|---|---|
| C1 | 逐个扫 12 个宫格（本命层） | 宫名 13px 加粗完整；右上干支（天干+地支）9px 完整 |
| C2 | 看主星行 | 12px，**最多 3 颗**，超出的显示「+N」；最多占 2 行（`.major` max-height 30px） |
| C3 | 看辅星行 | 9px，**最多 2 颗**，只露 1 行（`.minor` max-height 11px） |
| C4 | 按【**下**】键 1 次 → 切到**大限**层 | 每格宫名旁多一个 10px 的**运限宫名小标**（次级绿）。检查：小标有没有把干支挤出格子？有没有和本命宫名重叠？ |
| C5 | 在大限层再按【下】1 次 → **流年** | 宫内星曜后面的四化标记应换成带前缀的写法（「限禄」「流禄」），**本命那套标记在运限层整层不显示** |
| C6 | 在流年层看主星行有没有变长 | 运限层四化带前缀会占更多宽度，检查第 2 行是否被截断 |
| C7 | 看中宫 | 最多 10 行：标题 / 命主身主 / 层副行 / 层附行 / 四柱 / 分隔线 / 选中宫名(+运限小标) / 操作提示 / 状态行 / 示例盘行。**有没有超出中宫边界、有没有两行叠字** |

- 12 格的宫名 / 干支**无一截断**
- 主星行 ≤ 2 行且完整，辅星行完整
- 运限小标不与干支、本命宫名重叠，不溢出格子
- 中宫 9 行不溢出、不叠字

**不通过怎么办**：截断/重叠 → §3 第 15、16 条（改 `index.ink` 的 `.major`/`.minor`/`.palace-name`/`.fortune-name` 字号与 max-height）；运限层仍显示本命四化 → §3 第 17 条。

### D 准星通道（含倾斜通道降级链）

**目标**：确认**绝对方向传感器在真机到底能不能用**；能用就把准星调对，不能用就确认降级链走通，并测出倾斜通道的轴向与方向。

| 步 | 操作 | 观察点 |
|---|---|---|
| D1 | 戴上眼镜正视屏幕，看中宫状态行 | 记下传感器标签 |
| D2 | **若显示「头部准星」**（`AbsoluteOrientationSensor` 出了首帧） | 进入 D3 |
| D3 | 缓慢**连续**左右转头（一个动作里不要停），看选中宫 | 选中宫应随头部**连续**变化，**不是四档跳格**。偏航到约 ±22°（`CURSOR_DEFAULTS.yawRangeDeg = 22`）应到左右边界 |
| D4 | 缓慢抬头/低头 | 俯仰到约 ±16°（`pitchRangeDeg = 16`）到上下边界 |
| D5 | 把准星**走进中宫**（正中间那两格） | 选中宫**保持不变**（中宫不是宫位，`gridToBranch` 对中宫返回 null） |
| D6 | 把准星压在格子边缘来回蹭 | 边缘 0.2 范围内**不换宫**（`edgeGuard = 0.2`），不该来回跳 |
| D7 | **若显示「抬头选宫」** | 说明 1.5 秒内没等到准星首帧，已自动降级到加速度计通道（`SENSOR.FIRST_FRAME_TIMEOUT_MS = 1500`）。**记下来：这是本作品核心交互的降级**，必须报出去 |
| D8 | **若显示「抬头选宫」**：戴好眼镜不动 2 秒建立基准，然后抬头、每次回正后再低头 | 每次越过约 **12°**（`TILT_DEFAULTS.thresholdDeg = 12`）应切一宫；**保持倾斜不应连切多宫**（回中死区 `rearmDeg = 5`，必须回到 5° 以内才允许下一次） |
| D9 | 检查方向：抬头切到的是**下一宫还是上一宫** | 抬头与左右键同向 = 地支 +1（外圈顺时针：巳午未申酉戌亥子丑寅卯辰）。方向反了就是 `signFlip` 要改 |
| D10 | **若显示「镜腿选宫」** | 说明加速度计也失败了，只能靠镜腿键。**这是严重问题**，必须记录日志 |
| D11 | 查宿主是否需要显式 enable 绝对方向能力 | **待确认（需现场确认）**：Studio / Rokid Ai App 里是否有对应的传感器能力开关（位置未知） |

**通过标准**
- 准星通道**或**倾斜通道至少一条可用
- 准星通道可用时：连续二维、不跳格、压边缘不抖、落中宫不丢选择
- 倾斜通道可用时：12° 触发、5° 死区生效、不连切、方向与镜腿键一致
- 状态行标签与实际能力一致（**界面不能承诺做不到的事**）

**不通过怎么办**：低头没反应 → §3 第 4 条（`axis`）；方向反 → §3 第 5 条（`signFlip`）；准星左右反向 → §3 第 8 条；边缘抖 → §3 第 7 条；两个传感器全废 → §3 第 9 条。

### E 镜腿按键（巡宫 / 切层 / 确认 / 返回 / 手势误报）

**目标**：**十二宫全部可选**、**四层都能切**、两级返回语义正确、**手势不误触发**。

| 步 | 操作 | 观察点 |
|---|---|---|
| E1 | 在盘面态按【**左**】键 **12 次**，每按一次记中宫「选中宫」那一行 | 应走遍外圈 12 宫，不重复、不漏。**左键是逆着圈走**：从「巳」按左 → 辰 → 卯 → 寅 → 丑 → 子 → 亥 → 戌 → 酉 → 申 → 未 → 午，**第 13 次回到「巳」** |

### F 朗读（TTS）

**目标**：眼镜上**听得见**——每一步操作都有声音，解读正文能念完，能打断。

| 步 | 操作 | 观察点 |
|---|---|---|
| F1 | 盘面态按【确认】 | **先念宫名与主星**（如「夫妻宫，紫微化禄、天机」），随后念解读正文 |
| F2 | 听音质与语速 | 单色绿屏上正文动辄上千字，**TTS 是长文本唯一可行通道**，语速太慢/断续要记下来 |
| F3 | 打断测试：正文朗读中按【返回】 | 应立刻停止（`_closeOverlay()` → `stopSpeaking()`），不应继续念 |
| F4 | 叠声测试：连续快速按【确认】两次 | 不应两句叠在一起（`lib/tts.js` 用 `1200 + 文本长度 × 180 ms`（上限 15 s）估算时长做抑制） |
| F5 | 切层时听声音 | 应念出层标题（如「大限 32–41 岁」） |
| F6 | 追问浮层提交后 | 应念出回答 |

| F8 | 若**完全没声** | 判断走的是哪条路径：`wx.speech.playTTS` 还是 `speechSynthesis.speak`。**运行时给哪个待确认（需现场确认）**（T4） |

**通过标准**
- 确认键、切层、追问三处**都有声**
- 正文能完整念完，不卡死、不无限循环
- 可打断；不叠声

**不通过怎么办**：无声 → §3 第 13 条；叠声/断句怪 → §3 第 13 条（调 `lib/tts.js` 的 `1200 + len×180` 估算系数）。

### G 网络与服务端兜底

**目标**：**断网也能看盘**，网络失败**只降级不白屏**，网络恢复后解读能取到。

服务端固定地址：`https://ziwei.secondplanet.cc`，三个接口 `/api/agent/chart`（超时 8 s）、`/api/agent/reading`（10 s）、`/api/agent/ask`（40 s）—— `lib/api.js` `TIMEOUTS`。

| 步 | 操作 | 观察点 |
|---|---|---|
| G1 | 手机**开飞行模式**（断网），进智能体看盘面 | **盘面必须照常出**（端侧引擎本地算），只是网络类功能失效 |
| G2 | 断网状态下按【确认】 | 解读区显示「**这一段解读暂时取不到，盘面本身是端侧算的，不影响查看**」，**不白屏、不显示技术错误** |
| G3 | 断网状态下按【确认】→【确认】进追问 | 显示「**追问暂时不可用，盘面和解读不受影响**」 |
| G4 | 恢复网络（关飞行模式），再按【确认】 | 解读正文出现；浮层底部出现**引文形态标注**（`citationModeLabel`，当前应为降级模式） |
| G5 | 恢复网络后进追问 | 拿到真实回答并念出来 |
| G6 | **弱网**：手机连一个很慢的热点（或开限速），按【确认】 | 10 秒左右应降级为兜底文案，**界面不应卡死**（`reading` 超时 10 s） |
| G7 | 手机端直接验证接口可达 | 在手机浏览器打开 `https://ziwei.secondplanet.cc/api/agent/chart`，用 POST 发一组生辰参数（`{"year":1990,"month":1,"day":1,"hour":0,"gender":"male"}`），应返回十二宫 JSON。若手机都不通，问题在服务端/域名，不在眼镜 |
| G8 | 观察端侧与服务端的关系 | 盘面**永远**走端侧；只有解读与追问走服务端。断网时盘面不能受影响 |

**通过标准**
- 断网时盘面 100% 正常
- 四条失败路径都有兜底文案，**无一条白屏**
- 恢复网络后解读 / 追问能拿到，且引文形态标注可见
- 弱网下超时在预期内（10 s / 40 s），界面不假死

**不通过怎么办**：白屏 → §3 第 11 条；一直转圈不出兜底文案 → §3 第 11 条（检查 `wx.request` 是否命中、是否被 fetch 兜底拖死）；追问慢到没法演示 → §3 第 12 条。

### H 长跑稳定性

**目标**：**连续 10 分钟以上**不超时、不报错、不崩。

| 步 | 操作 | 观察点 |
|---|---|---|
| H1 | 起一段 ≥ 10 分钟的连续操作：巡宫 12 宫 → 切四层 → 确认朗读 → 追问，连续循环 | 全程不能白屏、不能卡死 |
| H2 | 期间故意插几次「断网 → 复网」 | 每次都要能自己恢复，不需要重启应用 |
| H3 | 期间做 3 次「返回 → 重说生辰 → 换盘」 | 每次都能换盘，不卡在旧盘 |
| H4 | 观察主观体验 | 帧率是否下降、发烫、明显卡顿（T5：内存/发热的量化观察方式**待确认**） |
| H5 | 结束后强杀应用进程，重新打开 | 首启正常，能读本机存档 |
| H6 | 看日志（T3：入口**待确认**） | 无 `[ziwei-agent] 排盘失败`、无 `app error`、无未捕获异常 |

**通过标准**
- 10 分钟连续操作：无白屏、无崩溃、无超时卡死
- 断网/复网 3 次全部自愈
- 换盘 3 次全部成功
- 结束后重启正常，日志无异常

**不通过怎么办**：白屏/崩溃 → §3 第 1、11 条；换盘后卡死 → §3 第 19 条；操作越来越慢 → 记下现象并保留日志，回来看 §3 第 13、20 条。

## 4. 录屏清单（提审视频必须覆盖的画面）

素材规格：**共 3–5 个，至少 1 图 + 1 视频**，支持 JPG/PNG/MP4；视频 ≤ 1 GB，**必须在真机上录**。现有 3 张图（流年盘面 / 本命盘面 / 应用图标），**视频仍缺**。
主版本建议：横屏 1920×1080 / 60fps / H.264 / ≤ 200 MB / ≤ 90 秒。

镜次沿用 `submit-kit/video-script.md`（S1–S9），下面只列**「看到什么才算数」**与**它由本清单哪一组背书**：

| 镜次 | 必须拍到的画面 | 什么算过关 | 背书组 |
|---|---|---|---|
| S1 开场说生辰 | 「说出你的生辰」提示浮层 → 用户开口 | 浮层出现且不遮挡盘面 | B |
| S2 出盘·端侧计算 | 十二宫盘面 + **中宫那行「端侧计算」清晰可读** | 「端侧计算」四字能被看清并停留 ≥ 2 秒；**不是「服务端计算」** | A + C |
| S3 准星·连续二维光标 | 一个动作里准星**连续**划过多格，跨格处不跳格；压边缘时停顿 | 路径是连续曲线；**剪成跳格就等于把差异点讲反了** | D |
| S4 时间层·上下键切层 | 层标题「本命盘」→「大限 xx–xx 岁」→「流年 干支 年份」→回本命；眼镜念出层名；格内四化换成「限禄/流禄」 | **按一次、切一次、中宫刷新一次**三者对得上；本命四化在运限层不显示 | E + C |
| S5 选中·落宫 + 外圈巡宫 | 准星停在某宫 → 按确认 → 浮层副行「本命X宫 · 维度」；补 1 秒镜头：**镜腿左右键沿外圈走完整一圈** | 外圈那一圈**走完不跳格**、十二宫全选得到；朗读声与落格是同一件事 | E + D |
| S6 解读·原文检索 | 解读浮层正文滚动，TTS 念出正文开头一两句 | **正文是现场检索回来的**（不是静态文字板）；接口当天不通就拍不成这一镜 | G |
| S7 降级·受限引文已处理 | 浮层底部两行小字拍清楚：① 引文形态标注 ②「传统文化学习与研究用 · 不构成医疗、法律、投资或人生决策建议」 | 两行**都入镜**、可读 | G |
| S8 复算·同一生辰同一张盘 | 快速重复输入同一次生辰，盘面再次出现且与 S2 逐格一致 | 两张盘**逐格一致**（加速可以，盘面本身要能看清） | B + A |
| S9 落版 | 作品名 + 一句话定位 + 数据集署名 + 免责声明 | 静置 ≥ 4 秒，保证截图能截全 | — |

**录屏前必做**
1. 先确认后端三个接口当天可用（§G7）—— S6/S7 依赖它。
2. 先确认 S2 的「端侧计算」是亮的 —— 端侧引擎没加载就没有运限层，S4 拍不出来。
3. **真实失败不许藏**：取不到就按界面原话拍（「这一段解读暂时取不到，盘面本身是端侧算的，不影响查看」）。
4. HUD 是单色绿盘面，**不要后期上色、不要加彩色描边**；字幕放画面下三分之一，不压住 HUD 中央。
5. 全片**不出现**「单击/双击」「已上架」「已通过真机测试」这类说法。

## 5. 最终判定：能不能提交初赛

### 5.1 硬门槛（**任意一条不过 → 不能提交初赛**）

| # | 门槛 | 判定口径 | 对应组 |
|---|---|---|---|
| 1 | **全链路不白屏** | 首启、语音录入失败、解读失败、追问失败、运限层不可用——**五种情况下界面都有内容** | A/B/G |
| 2 | **不超时** | 首启 ≤ 3 s 出盘；解读 ≤ 10 s 出结果或兜底；追问 ≤ 40 s 出结果或兜底 | A/G |
| 3 | **无报错日志** | 真机日志无「排盘失败」、无 `app error`、无未捕获异常、无资源加载失败 | A/H |
| 4 | **端侧计算生效** | 中宫末行显示「**端侧计算**」，且运限层可用（四层能切） | A/E |
| 5 | **四层可切** | 本命 / 大限 / 流年 / 流月 **四层都能按出来**，标题正确，无空白层 | E |
| 6 | **十二宫可达** | 左右键走满外圈一圈，十二宫全选得到 | E |
| 7 | **手势不误触发** | 滑动镜腿附近 20 次无误选宫 / 误确认 | E |
| 8 | **听得见** | 确认键、切层、追问三处都有声，可打断，不叠声 | F |
| 9 | **断网可看盘** | 飞行模式下盘面照常出，解读/追问给出兜底文案 | G |
| 10 | **长跑不崩** | 连续 ≥ 10 分钟操作无白屏/无崩溃/无卡死，重启正常 | H |
