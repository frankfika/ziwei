## 2. 设计方向（拍板）

### 方向名：**「一屏一件事 · 分层退让」**

三条铁律：

1. **一屏一件事**
   盘面页只讲「盘」；对话页只讲「这一问一答」。
   凡是跟当前任务无关的（十二宫图例、免责、合规声明、命盘库计数、操作手册），一律**移出阅读流**，进底部固定条或直接删。
2. **一句话只说一次**
   同一个信息（层名、焦点宫、建议语、引擎状态）在**一页内只能出现一处**。
3. **提示与内容分层**
   「内容」走大字；「操作提示」走底部固定细条，永远不跟正文抢行。
   元信息（焦点/层）用**一行小字**放在内容上方，不夹在正文段落里。

### 视觉规范（单色绿屏）

| 项 | 值 | 说明 |
|---|---|---|
| 字号梯度 | **22 / 15 / 12 / 10**（共 4 级，不许第 5 级） | 正文 22，宫名/小标题 15，次要 12，角标/提示 10 |
| 行高 | 正文 1.55；小字 1.4 | 480px 宽一行约 19 个汉字（22px），偏长 → 正文段落需靠留白断行 |
| 字重 | 只有 3 档：`bold`（宫名/主星/问题）/ `normal`（正文）/ 靠透明度降级（次要） | 不做 600/500 伪粗 |
| 透明度 | 100% / 62% / 38% 三档 | 单色屏靠这个拉层次，**不加颜色** |
| 细线 | 1px，透明度 22%，只用于「不同语义块之间」 | 全页细线 ≤ 3 条 |
| 间距梯度 | 4 / 8 / 12 / 16 px | 来自 Utopia 比例，禁拍脑袋值 |
| 分区 | 用 **1px 细线 + 上下 12px 留白**，不用卡片、不用圆角、不用阴影 | 单色屏上圆角和阴影只会变噪点 |
| 禁 | 满屏字、居中大标题、emoji、渐变、发光、卡片套卡片、颜色区分语义 | 去 AI 味清单 |

## 3. 逐屏规格

### 3.1 盘面页（board）

**结构（自上而下）**

```
十二宫（4×4，保持现有几何布局 .p0–.p11 不动）
  每格内部：
    第一行  宫名（15 bold）            右上角 干支（10, 38%）
    第二行  主星（22 bold）
    第三行  辅星 + 四化（12, 62%）
    运限宫名小标（10, 38%）—— 仅当处于运限层才出现
  选中宫：1px 实线描边（100%）+ 宫名加粗；不再额外加色
中宫（120×176，保持 .center 位置不动）
  第 1 行  焦点：「命宫」15 bold           ← 只留一个宫名
  第 2 行  副信息：「本命 · 大限 32-41 岁」12, 62%   ← 层与焦点合成一行，不分行
  ───── 1px 细线
  第 3 行  主行动文案：「试试问：今年事业怎么样」12, 62%
            （示例盘时改为「说出生辰，或直接问我」）
  第 4 行  状态：「端侧计算」10, 38%
  ✗ 删掉：focus-detail 单独行、摘要解读（digest-a/digest-q）、操作手势三连行
  ✗ 操作手势从盘面页中宫移到 —— 见 3.3
```

> **注意**：`digest-q` / `digest-a`（中宫摘要问答）**整块删除**，解读只在对话页出现一次。
> 若删除后 `digestQuestion/digestAnswer/digestLead` 等 data 字段不再被模板引用，
> 允许保留 data 字段但必须删掉对应模板节点与相关样式。

### 3.2 对话页（chat）

**结构（自上而下）**

```
┌ 固定头（1 行，12px, 62%） ───────────────────────────┐
│ 本命盘 · 命宫                              ← 只此一行 │
└──────────────────────────────────────────────────────┘
  ↑ 合并原 .strip-title + .strip-focus + 焦点；
    ✗ 删除 .strip-row（12 个宫名缩写）—— 盘面页已有，纯重复；
    ✗ 删除 .chat-disclaimer 独立行（免责移到固定底条）

  正文区（scroll-view）
    · 用户问句：22 bold，左侧 1px 竖线缩进（唯一一条竖线）
    · 回答正文：22 normal，行高 1.55，段间 12px
    · 正文里的列表项：22 normal，缩进 12px
    ✗ 删除 .turn-tag 整行（「最新 推演 焦点… 引文已降级…」）
      ——「焦点/层」并进固定头；「引文已降级…」移到固定底条
    ✗ 正文末尾的「双击镜腿问这一句：…」删掉（底部已有）

  固定底条（1 行 + 极小字 1 行）
    第 1 行  左：建议语「双击问：今年事业怎么样」（12, 100%）
                右：状态「端侧计算」（10, 38%）
    第 2 行  10, 38%：「仅供传统文化学习与研究之用 · 不构成医疗、法律、投资或人生决策建议」
                （免责在此，只此一处）
                「引文已降级」若必须显示，合并到这一行尾部
                「命盘库 N 张」合并到这一行（不再单独一行）
  ✗ 删除 .chat-lib 独立块、.chat-ask-single 独立块、.chat-foot 的两行结构
  · 有键盘的宿主（canType=true）：打字框 + 4 个建议语 chip 保留，
    但压缩为 2 行 chip + 1 行输入框，且**建议语 chip 与固定底条的建议语必须去重**
    （chip 显示纯问题文本，不带「双击问：」前缀）
```

### 3.3 操作提示（跨页统一）

- **操作手势提示只出现在对话页固定底条的一行**，盘面页不再重复。
- 盘面页如果一定要提示手势，**只保留一行**：`滑动选宫　单击问这宫　双击切层`（10px, 38%），
  放在中宫最后一行，且**与状态行合并为一行**（用间隔符 `·` 分隔），不是两行。
- **同一句话不出现两次**：`hintLine` 只能被渲染一次。

### 3.4 录入浮层（overlay）

保持结构，收紧字号：`overlay-title` 22 bold，`overlay-body` 15，
格式提示行 12/38%，错误文案 15/100%（单色屏用字重区分，不用红）。

## 4. 实现约束（必须遵守）

1. **只改 `apps/rokid-agent/` 下的文件**，尤其 `pages/index/index.ink` 的 `<page>` 模板与 `<style>`；
   **绝对不要动 `apps/web/`**。
2. **不改手势语义**：`index.ink` 的 `_dispatchKey` 映射表（滑动=选宫/滚正文、单击=问这宫/开口问、
   双击=切层/问建议语、返回=退出/回盘面）**一个字都不能改**。本次**只改视觉与信息架构**。
3. **不改后端调用**：`/api/agent/chart|reading|ask` 的调用与超时不动。
4. **解读正文一个字都不能少**（数据集原文硬规则）。只改排版，不改内容。
5. **保留** `.p0–.p11` 十二宫几何布局坐标（`index.ink:2083-2094`）—— 改版不动盘面几何。
6. **保留** 端侧引擎路径（`assets/engine.js`）、`lib/` 下所有模块的行为。
7. **保留** 所有 `bindtap` 事件绑定与 `ink:if` / `ink:for` 的功能语义（`onSug0-3`、`onSendTyped`、
   `onOpenProfilePanel`、`onProfilePrev/Next/Pick` 等一个都不能少）。
8. **不动** `<script def>` 里的 data schema（除非某个字段彻底不再被模板使用）。
