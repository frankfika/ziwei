# 提交留档

这个目录放**已经正式提交给中国版权保护中心的那一版**打印稿，文件名带提交日期，例如：

```
紫微星盘-源程序-2026-11-15.pdf
紫微星盘-软件说明书-2026-11-15.pdf
```

**为什么要单独留档**：`submit-kit/copyright/` 下的 PDF 是**生成物**（`.gitignore` 已排除），
随仓库源码每改一次就变一次。而登记机构收到的是**某一个具体版本** ——
如果以后源码改了、生成物被覆盖，就没法证明「交出去的那一版到底是什么」。

**规则**：
- 每次正式提交后，把当次的两份 PDF 复制到这个目录，文件名带提交日期，**提交入库**；
- 一旦提交，**不要再改**这两份文件（它们是历史凭证）；
- 提交前先跑 `npm run copyright:materials` 重新生成，生成结果与此处留档的版本不一致时，
  要么改源码后重新提交登记（走**变更/补充登记**流程），要么确认当前留档仍是提交的那一版。
