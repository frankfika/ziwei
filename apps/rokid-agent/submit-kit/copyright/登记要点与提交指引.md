### 登记依据（写作口径）

登记申请表的「软件功能和技术特点」一栏要写 200 字左右的功能简介，**用词必须与说明书一致**：

- 呈现传统术数的**盘面结构**（十二宫、星曜分布、五行局），同一生辰在任何设备上得到同一张盘；
- 解读文本**从公开数据集检索原文**，不做自由生成；
- 运行形态为智能眼镜端 AIUI 智能体，端侧完成确定性排盘，辅以语音朗读与追问。

**不写**任何「预测 / 运势 / 准确率」类表述 —— 与赛事合规口径（`PROPOSAL.md` §9.3）保持一致。
软著申请表是给登记机构的法律文书，措辞必须与对外材料同一套红线。

### 材料规格核对（已实测）

**源程序 PDF**
- 61 页 = 前 30 页 + **省略说明 1 页** + 后 30 页；
- 原始合集 81 页 / 4022 行，每页**恰好 50 行**（硬高度行框控制，不靠 CSS 自动分页）；
- 页眉：**软件名称 + 版本号**（左）、著作权人 + 页码（右）；页脚：软件名 + 页码；
- 每行带连续行号，超宽行折行并以 `原行号*` 标注续行，行号可与仓库源码逐行核对；
- 中间省略的 21 页有一页**明写**省略范围与行数（软著允许省略中段，但要说清楚）。

**说明书 PDF**
- 8 页（封面 + 目录 + 10 章正文 + 附录 A），A4，60 页上限内；
- 封面载明软件名称 / 版本号 / 著作权人 / 开发完成日期 / 首次发表状态。

### 重新生成

```bash
node apps/rokid-agent/scripts/build-copyright-materials.mjs
# 或只出一件：
node apps/rokid-agent/scripts/build-copyright-materials.mjs --only source
node apps/rokid-agent/scripts/build-copyright-materials.mjs --only manual
```

脚本会先跑**合规门禁**（TIER1 硬禁用命中即拒绝生成对外材料），
再拼源程序合集、切页、渲染 PDF。改过源码或说明书后要重跑一次。

## 3. 提交步骤（中国版权保护中心）

1. **注册账号**：中国版权保护中心官网（`ccopyright.com.cn`）注册个人账号，实名认证。
2. **在线填写申请表**：软件基本信息按「一」的表格填；「软件功能和技术特点」用上面的写作口径。
3. **上传材料**：源程序 PDF、说明书 PDF、身份证正反面。
4. **打印签章**：下载申请表 → 本人**手写签名** → 扫描成 PDF（电子签章多数地区不被接受）。
5. **缴费**：受理后缴费，标准以官网为准（个人非营利性质软件开发有相应优惠，以官网最新政策为准）。
6. **等待受理与审查**：受理后进入审查，审查通过颁发《软件著作权登记证书》。
7. **下载证书**：证书电子版可下载，用于赛事材料补充或上架材料。

### 时间预期

| 环节 | 预期 |
|---|---|
| 在线填写 + 上传 + 签章 | 1 个工作日 |
| 受理（形式审查） | 3–10 个工作日 |
| 实质审查 | 20–40 个工作日 |
| 领证 | 受理后约 2–3 个月 |

> ⚠️ 以上为经验区间，**以中国版权保护中心官网公示为准**，本文件不作为时限承诺。
> 排期上给到 **2027-01-28 报名截止前**留足余量：11 月中旬提交材料，1 月上旬拿到证书最理想；
> 拿不到也不影响报名（因为赛规未列此为必需项）。
