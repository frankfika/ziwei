## 1 引言

### 1.1 编写目的

本文档是「紫微星盘」软件的操作与结构说明书，供软件著作权登记、用户使用参考与后续维护使用。

### 1.2 软件背景

「紫微星盘」是一款基于传统紫微斗数排盘规则的**结构化学习工具**。它把一项流传数百年的排盘算法，封装成可以在智能眼镜上「一眼看懂、开口就问」的学习体验：用户说出生辰，软件在端侧用确定性规则排出十二宫盘面，用户抬头低头用准星选中宫位，眼镜随即朗读该宫的传统解读原文，并支持就这一张盘继续追问。

软件的设计出发点有三条，且这三条贯穿全部实现：

1. **计算必须可复算。** 十二宫的星曜落位、五行局、大限，全部由固定算法计算得出，同一生辰在任何设备上得到同一张盘。用户可以自己复核，评审也可以复核。
2. **解读必须有出处。** 文字不是模型编的，而是从一份公开数据集里检索出来的原文；模型只负责把原文组织成一段话，不参与计算，也不自由发挥。
3. **不做超出边界的承诺。** 软件呈现的是盘面结构与传统文本，不对结果好坏下判断，不给任何形式的量化承诺。

### 1.3 术语约定

本文档中「盘面」「十二宫」指代排盘结果的结构化图形；「解读文本」指代从数据集检索得到的传统原文；「传统术数」指代紫微斗数这一套历法与星曜排布规则。所有涉及解读的表述一律指**文本呈现**，不指代对个人未来的判断。

## 2 软件概述

### 2.1 功能总览

| 编号 | 功能 | 说明 | 所在层 |
|---|---|---|---|
| F1 | 生辰解析 | 把口语化的时间表达解析为结构化出生参数 | 端侧 |
| F2 | 排盘 | 按传统规则排出十二宫盘面（主星、四化、五行局） | 端侧引擎 |
| F3 | 运限层 | 在本命盘之上叠加**大限 / 流年 / 流月**三层，共四层 | 端侧引擎 |
| F4 | 准星选宫 | 用头部姿态（绝对方向传感器）指向格子选中宫位 | 端侧 |
| F5 | 巡宫 | 用镜腿按键沿十二宫外圈逐宫移动 | 端侧 |
| F6 | 朗读 | 用语音合成逐宫朗读解读原文 | 端侧 |
| F7 | 识别 | 用语音识别接收用户的生辰与追问 | 端侧 |
| F8 | 解读检索 | 按出生参数检索数据集原文，返回结构化解读 | 服务端 |
| F9 | 追问 | 基于当前盘面回答用户追问 | 服务端 |
| F10 | 引文降级 | 对许可受限的引文做占位降级并在界面披露 | 服务端 + 端侧 |
| F11 | 本地存储 | 记住最近一次出生参数与当前层，减少重复输入 | 端侧 |
| F12 | 免责声明 | 在解读浮层内展示数据来源与使用须知 | 端侧 |

### 2.2 关键设计约束

1. **端侧优先。** 排盘不依赖网络：端侧引擎是一个随包分发的单文件模块（`assets/engine.js`，约 860 KB），在设备运行时动态加载。只有解读文本与追问需要访问服务端。
2. **服务端只做检索，不做计算。** 服务端接收五个参数（`year` / `month` / `day` / `hour` / `gender`），用它们拼出检索键去数据集取原文，不参与任何星曜推算。
3. **检索键严格一致。** 检索键格式为 `YYYY-MM-DD-时辰序号-性别`，其中时辰序号取 0–11（子时为 0）。端侧与服务端使用同一套编码，任何一端改了编码都会导致检索落空，因此该映射由同一份常量表维护并有自动化断言钉死。
4. **不申请多余权限。** 应用的权限声明只有一项：`INTERNET`。语音识别与语音合成均通过宿主提供的能力接口调用，不额外申请麦克风权限，也不使用摄像头、定位或媒体库。
5. **不承诺结果。** 界面文案不使用任何结果导向的形容词，不出现数字化的结论表述。

## 3 运行环境与安装

### 3.1 运行环境

| 项目 | 要求 |
|---|---|
| 宿主平台 | Rokid AI Glasses（AIUI 运行时） |
| 界面形态 | 480 × 352 单色绿显示，分辨率固定 |
| 网络 | 仅解读检索与追问需要 `INTERNET` |
| 存储 | 本地键值存储，用于最近出生参数与当前运限层 |
| 权限 | `INTERNET`（唯一） |

### 3.2 安装与分发

本软件以 AIUI 智能体工程形式分发，工程内包含：

```
app.json          应用配置（页面列表、权限、窗口标题）
app.js            应用入口
pages/index/      主页面（.ink 模板）
lib/              功能模块（纯 JavaScript，无构建步骤）
assets/engine.js  端侧排盘引擎（单文件产物）
types/            类型声明
```

工程可直接导入 AIUI Studio 进行模拟调试、真机调试与打包，产物为 `.aix` 安装包。

### 3.3 首次启动

1. 智能体启动后进入主页面，界面显示引导语「说出你的生辰」。
2. 引导语与示例采用**日常口语**（如「1990年1月1日 早上 男」），不要求用户掌握「子时、丑时」这类术语。用户明确表示不知道时辰时，软件按午时排盘，并在盘面上标注「时辰按午时估算」；估算结果一律明示，不静默给出。
3. 若设备未授予麦克风能力或语音识别不可用，界面**不会白屏**，而是退化为可手动选择的输入方式，并给出示例格式。
4. 用户完成一次输入后，软件会把解析结果写入本地存储，后续进入可直接使用。

## 4 总体结构与设计说明

### 4.1 分层

```
┌─────────────────────────────────────────────┐
│  界面层  pages/index/index.ink               │
│  盘面绘制 / 准星 / 按键 / 朗读 / 追问浮层      │
├─────────────────────────────────────────────┤
│  模块层  lib/*.js                            │
│  birth-parser  chart-layout  head-cursor    │
│  time-layer    chart-source  api  tts       │
│  voice-input   storage      key-guard       │
├─────────────────────────────────────────────┤
│  引擎层  assets/engine.js（单文件产物）        │
│  排盘 · 大限 · 流年 · 流月                    │
└─────────────────────────────────────────────┘
                    │
                    ▼  仅解读与追问走网络
        ┌───────────────────────────┐
        │  服务端 /api/agent/        │
        │  chart  reading  ask      │
        └───────────────────────────┘
```

### 4.2 模块职责

| 模块 | 职责 | 关键实现要点 |
|---|---|---|
| `birth-parser.js` | 口语生辰 → 结构化参数 | 支持「1990年1月1日 早上 男」「一九九零年一月一日 晚上十一点 女」「2000年2月29号 丑时」等写法；时辰词表区分早晚子时；时辰缺失或用户明说不知道时按午时兜底，并标记为估算供界面明示 |
| `chart-layout.js` | 盘面几何与宫位映射 | 4×4 四四方阵 + 中宫；外圈巡宫顺序为巳午未申酉戌亥子丑寅卯辰，+1 即地支 +1，与抬头低头切宫同向 |
| `head-cursor.js` | 绝对方向 → 网格坐标 | 四元数转欧拉角，映射到十二宫网格；带 12° 切换阈值与 5° 回中死区；传感器不可用时 1.5 秒超时降级 |
| `time-layer.js` | 四层运限的显示与切层 | 本命 / 大限 / 流年 / 流月；运限四化带「限 / 流」前缀；焦点追问自动切到对应层 |
| `chart-source.js` | 盘面数据来源仲裁 | 端侧引擎优先，失败时回落服务端排盘接口 |
| `api.js` | 网络出口封装 | `wx.request` 优先、`fetch` 兜底，统一超时与错误归一 |
| `tts.js` | 语音合成封装 | `wx.speech.playTTS` 优先、`speechSynthesis.speak` 兜底 |
| `voice-input.js` | 语音识别封装 | `wx.speech.startRecognition` 优先、`SpeechRecognition` 兜底 |
| `storage.js` | 本地存储 | 最近出生参数、当前运限层 |
| `key-guard.js` | 按键去抖 | 同 `event.code` 在 150 ms 内只认一次，规避滑动时的误报 |

### 4.3 端侧引擎

排盘能力由 `packages/chart-engine` 编译打包为单文件 `assets/engine.js`，随智能体一并分发。打包产物与源码引擎的输出做**整对象逐字段比对**（不做归一化），确保「端上算出来的」与「服务端算出来的」完全一致。

导出的能力包括：基础排盘（十二宫）、大限层、流年层、流月层，以及供界面使用的盘面结构与四化信息。

引擎在设备运行时动态加载；加载失败时界面静默回落到服务端排盘，并在中宫标注当前计算来源。

## 5 界面说明

### 5.1 主界面布局

主界面为固定 480 × 352 的单色绿显示，采用传统四四方阵：

```
┌─────────┬─────────┬─────────┬─────────┐
│   巳    │   午    │   未    │   申    │
├─────────┼─────────┼─────────┼─────────┤
│   辰    │         │         │   酉    │
│         │   中宫  │         │         │
├─────────┼─────────┼─────────┼─────────┤
│   卯    │         │         │   戌    │
│         │ 运限层  │         │         │
├─────────┼─────────┼─────────┼─────────┤
│   寅    │   丑    │   子    │   亥    │
└─────────┴─────────┴─────────┴─────────┘
```

每宫显示：宫位地支、主星、四化标记、该宫解读的一行摘要。中宫显示：当前运限层名称、当前选中宫位、计算来源、层切换提示。

### 5.2 四层运限

| 层 | 名称显示 | 说明 |
|---|---|---|
| 第 1 层 | 本命盘 | 出生时的本命盘面 |
| 第 2 层 | 大限 | 十年一阶段的大限盘面 |
| 第 3 层 | 流年 | 当年的流年盘面 |
| 第 4 层 | 流月 | 当月的流月盘面 |

切换方式：镜腿按键的上下方向。四层均可朗读；某层算不出来时自动跳过该层，不出现空白层。

### 5.3 解读浮层

选中宫位后，界面弹出解读浮层，内容依次为：

1. 宫位与主星摘要
2. 从数据集检索到的**十三维传统解读原文**
3. 引文形态披露（见 7.3）
4. 数据来源与免责声明一行

## 6 操作说明

### 6.1 输入生辰

三种方式，任选其一：

| 方式 | 操作 | 说明 |
|---|---|---|
| 语音 | 说「1990年1月1日 早上 男」 | 语音识别可用时为首选；说出「大概几点」「早上」「晚上」等日常说法均可 |
| 手动 | 按提示在文本框输入同样的内容 | 语音不可用时的兜底路径 |
| 沿用 | 直接进入 | 已存过出生参数时自动沿用 |

解析成功后，界面显示解析结果确认（年 / 月 / 日 / 时辰 / 性别），随后自动排盘。
用户无法提供时辰时，软件按午时排盘并在盘面上标注「时辰按午时估算」，提示该结果含估算成分。

### 6.2 选宫

- **准星方式（主）**：把头指向某个宫位，准星落点高亮该宫；再点按镜腿按键确认选中。
- **巡宫方式（辅）**：用镜腿按键的左右方向沿外圈逐宫移动，十二宫全覆盖，与准星方式叠加使用。

选中后立即朗读该宫解读。

### 6.3 切层

用镜腿按键的上下方向在四层运限之间切换。切换后准星位置与选中宫位保持不变，可直接继续朗读。

### 6.4 追问

在解读浮层中提问（例如「今年这一层怎么看」），软件把当前盘面上下文（当前层、当前宫位）与问题一并提交给服务端，返回针对该宫、该层的补充说明。

追问焦点会自动切层：问「今年」切到流年，问「大限」切到大限，未指明则停留在当前层。

### 6.5 按键一览

| 按键 | 功能 |
|---|---|
| 单击 | 确认当前准星宫位 / 确认追问 |
| 上 | 切换到上一运限层 |
| 下 | 切换到下一运限层 |
| 左 | 沿外圈移动到前一宫 |
| 右 | 沿外圈移动到后一宫 |

按键经 `key-guard.js` 做 150 ms 同码去抖，避免滑动时误报。

## 7 数据与隐私说明

### 7.1 本地优先

生辰、盘面、对话记录**只存本机**。软件不上传除排盘所必需的五个出生参数之外的任何内容。

### 7.2 出网内容

只有两类请求会出网：

| 场景 | 请求 | 出网内容 |
|---|---|---|
| 解读 | `POST /api/agent/reading` | 五个出生参数 |
| 追问 | `POST /api/agent/ask` | 五个出生参数 + 问题文本 + 当前层与宫位上下文 |

### 7.3 引文降级

解读数据集的许可为 CC BY 4.0，但数据集中收录的部分前人原话来自许可为 NC-SA（非商业性、相同方式共享）的来源，不在可商用范围内。软件在服务端输出前对这类受限引文做**占位降级**（以占位符替代正文），并在响应中下发当前引文形态（`inline` / `full`），由眼镜端在解读浮层内明确标注。降级在输入层、输出层、提示词层三处同时设防。

### 7.4 署名

应用内「关于」页与提交材料中均完整展示数据集的**来源、作者、许可**三项信息。

## 8 异常处理与容错

软件对每一类失败路径都有明确的兜底表现，**任何失败都不会导致白屏或静默无响应**：

| 异常 | 表现 |
|---|---|
| 语音识别不可用 | 退化为手动输入，界面显示示例格式 |
| 生辰无法解析 | 提示重说，并给出格式示例 |
| 端侧引擎加载失败 | 静默回落服务端排盘，中宫标注计算来源 |
| 服务端不可达 / 超时 | 显示可重试提示，保留当前盘面与输入内容 |
| 某一运限层算不出 | 自动跳过该层，不出现空白层 |
| 传感器不可用 | 1.5 秒首帧超时后放弃准星通道，保留按键巡宫 |
| 按键滑动误报 | 同码 150 ms 去抖拦截 |
| 引文受限 | 占位降级 + 界面披露引文形态 |

## 10 常见问题

**Q1：同一个生辰，为什么每次排出来的盘都一样？**
因为排盘不经过任何模型，全部由固定规则计算，同一生辰在任何设备上得到同一张盘。

**Q2：为什么同一段解读文字在不同设备上读出来可能有差异？**
文字本身来自数据集原文检索，是确定的；差异只可能来自语音合成的发音差异。

**Q3：解读文字是模型现写的吗？**
不是。文字是数据集原文检索的结果，模型只负责把原文组织成一段可朗读的话。

**Q4：为什么某些地方显示的是占位内容？**
数据集里部分引用的许可不在可商用范围内，这类内容在输出前被降级为占位，界面上会明确标注当前引文形态。

**Q5：能不能用耳机听？**
朗读走宿主提供的语音合成能力，输出到设备当前默认的音频通道。

**Q6：我的生辰会被传到哪里？**
只传排盘所必需的五个参数用于检索解读原文，其余内容保存在本机。

**Q7：为什么某一层运限是空的？**
该层算不出来时会自动跳过，不影响其他层。

**Q8：准星不动怎么办？**
准星依赖绝对方向传感器，传感器不可用时软件会自动放弃该通道，按键巡宫始终可用。
