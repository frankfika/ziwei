# 演示视频分镜脚本 · 紫微星盘

> **总时长：88 秒**（要求 ≤ 90 秒）
> **目的**：让评审在不看代码、不读策划案的情况下，看懂四个差异点。
> **旁白总字数：285 字**（按每分钟约 250 字朗读约 68 秒，其余 20 秒留给画面停顿、TTS 念正文和留白）。

**四个差异点标记（剪辑时不可删）**

| 标记 | 差异点 | 对应镜次 |
|---|---|---|
| ① | 头部准星是**连续二维光标** | S3 |
| ② | 排盘**零模型、可复算** | S2、S8 |
| ③ | 解读来自 **674,976 盘公开数据集原文检索**，**受限引文已降级** | S6、S7 |
| ④ | 运限四层在**端侧**切换，给的是**结构定位** | S4 |

> **手势口径**（2026-11-10 起，按真机实测改写）：
> 镜腿前后滑动 = 沿**盘面外圈**巡宫（巳午未申酉戌亥子丑寅卯辰，十二宫全覆盖，这一圈正好是十二宫序）；
> 轻点一下镜腿 = 听该宫解读，在解读浮层里再轻点一下 = 追问；
> 连点两下镜腿 = 切换时间层（本命 → 大限 → 流年 → 流月 → 本命）；返回键 = 退出。
> 唯一例外：端侧引擎没加载、压根没有运限层时，连点两下没有反应。
>
> ⚠️ 旧脚本写的「左右键巡宫 / 上下键切层 / 确认键」是**按键视角**的说法，
> 而真机上镜腿只有手势（滑动 / 轻点 / 连点两下），没有独立的上下键 ——
> 一次滑动发的是**一对**方向键，上下键只是配对键。
> 商店 v1.0.11 就是因为「上下键切层」在真机上不成立而被驳回，本脚本同步改成手势口径。

## 分镜表

### S1 · 开场 —— 说出生辰　`0:00 – 0:07`（7 秒）

| 项 | 内容 |
|---|---|
| 画面内容 | 第一人称视角，戴上眼镜。镜头抬起，HUD 上出现「说出你的生辰」提示浮层。用户开口。 |
| 旁白 | 「这是 Rokid AI Glasses。戴上它，说出你的生辰。」 |
| 字幕 | `说出生辰 → 出盘` |
| 剪辑 | 不要配激昂音乐。前 7 秒用环境底噪 + 识别提示音，把注意力留给画面。 |

### S2 · 出盘 —— 端侧计算　`0:07 – 0:17`（10 秒）　**〔差异点 ②〕**

| 项 | 内容 |
|---|---|
| 画面内容 | HUD 出现 4×4 十二宫盘面（中宫两格）。**镜头推近中宫**，中宫下方一行小字「端侧计算」清晰可读。命宫格加粗描边。 |
| 旁白 | 「盘面出来了。宫位、主星、安星、五行局、大限，全部由固定规则算出，不经过模型。中宫写着：端侧计算。」 |
| 字幕 | `排盘不经过模型 · 端侧计算` |
| 剪辑 | 「端侧计算」四个字用高亮框单独框住，停留不少于 2 秒。 |

### S3 · 准星 —— 连续二维光标　`0:17 – 0:32`（15 秒）　**〔差异点 ①〕**

| 项 | 内容 |
|---|---|
| 画面内容 | 准星出现在盘面上。**缓慢连续地**先左右移动、再上下移动，跨越多格，中间**不要跳格**。准星压到格子边缘时明显停顿一下（边缘保护带）。 |
| 旁白 | 「看盘面。准星跟着你的头走——左右二十二度，上下十六度，覆盖整张盘。它是连续的二维光标，不是四个按钮，也不是点一下头切一格。」 |
| 字幕 | `准星 = 头部绝对朝向 → 连续二维光标` |
| 剪辑 | 这一镜**不要剪碎**。评审要看见的是「连续」：一个动作里准星划过的路径必须是连续的曲线，剪切成跳格就等于把差异点讲反了。 |

### S4 · 时间层 —— 连点两下切层　`0:32 – 0:41`（9 秒）　**〔差异点 ④〕**

| 项 | 内容 |
|---|---|
| 画面内容 | 准星仍停在刚才那一宫。**连点两下镜腿**，中宫标题从「本命盘」换成「大限 32–41 岁」，再换成「流年 丙午 2026」，眼镜同时把层标题念出来；中宫第 2 行换成本层的命宫落位，第 3 行换成本层四化摘要（禄 / 权 / 科 / 忌各一颗星）。宫格里星曜后面的四化标记**换成带前缀的写法**（「限禄」「流禄」），本命那一套标记在运限层不显示。 |
| 旁白 | 「连点两下切层：本命、大限、流年、流月。每层显示自己的命宫落位和四化引动。」 |
| 字幕 | `连点两下切时间层 · 四层在端侧算` |
| 剪辑 | 切层动作要**连贯**：按一次、切一次、中宫刷新一次，三者对得上。切到流年层时停住 2 秒，让「流年 丙午 2026」这行标题和本层命宫落位看清。 |

### S5 · 选中 —— 落到夫妻宫并确认　`0:41 – 0:49`（8 秒）

| 项 | 内容 |
|---|---|
| 画面内容 | 准星停在夫妻宫，该格描边加粗。**轻点一下镜腿**，音频念出这一宫的宫名与主星，浮层标题下方一行小字标出这段解读对应本命哪一宫、哪一维（「本命夫妻宫 · 感情」；若当前在运限层，后面还会跟一句「本层为 X 宫」）。**补一个 1 秒镜头**：镜腿前后滑动沿盘面外圈依次巡过十二宫（巳午未申酉戌亥子丑寅卯辰），十二宫全部选得到。 |
| 旁白 | 「准星停在夫妻宫，轻点一下镜腿。滑动沿外圈巡宫，十二宫全覆盖。」 |
| 字幕 | `落格即选中` |
| 剪辑 | 留 1.5 秒空白，只留 TTS 的「夫妻宫」这一声——让人听见「选哪格」和「声音」是同一件事。外圈那个补镜要**走完一整圈**，中途不要跳格。 |

### S6 · 解读 —— 原文检索　`0:49 – 1:02`（13 秒）　**〔差异点 ③ 前半〕**

## 录制与剪辑要求

### 必须满足的录制前置条件

1. **必须真机录制。** 网页端模拟没有 IMU，准星通道跑不起来；用模拟画面代替真机在评审里是硬伤。
2. **拍之前先确认后端三个接口仍然可用。** S6 的解读文字来自 `/api/agent/reading`，S7 的引文形态标注来自响应里的 `citationModeLabel`——**接口当天不通就拍不出这两镜**。这三个接口已部署到生产域名并实测通过（2026-11-07 复测：三个均返回 200，解读接口返回 `citationMode: inline`），但演示当天仍要再验一次，别拿静态文字板冒充检索结果。
3. **S4 的运限层要求端侧引擎在跑。** 中宫那行「端侧计算」在屏才切得到层：端侧引擎没加载、走服务端兜底时运限层整体不可用，界面只剩本命盘，这一镜拍不出来。拍之前先确认 S2 的「端侧计算」是亮的再往下走。
4. **真实失败不许藏。** 如果某个环节真的取不到，按界面上写的原话（「这一段解读暂时取不到，盘面本身是端侧算的，不影响查看」）如实拍，或改拍其他镜次。

### 画面与字幕规范

- HUD 是 480×352 单色绿屏，**盘面本身只有单色绿**，不要后期上色或加彩虹描边。
- 字幕统一放画面下三分之一，**不要压住 HUD 中央盘面**。
- 单条字幕控制在 16 个中文字以内，超过就换行或拆条。
- 不要加产品 logo 动画、不要加转场特效库。

### 绝对不要出现的内容

- 任何形式的量化承诺（百分比、比例、"多准"一类的结论性表述）——一个都不许出现，包括口播和字幕。
- 「已上架」「已通过真机测试」「官方合作」这类不实表述。
- 未来时承诺（「即将上线全量用户」之类）。
- **把运限层说成「运势」「转运」一类。** 运限层给的是结构定位（这层的命宫落在哪一宫、哪几个宫被四化引动），口播和字幕都按这个说法，不要往「预测」上靠。

## 如果需要压到 60 秒

删 **S5**（8 秒）和 **S8**（8 秒），再把 S1 压到 5 秒、S2 压到 8 秒、S4 压到 8 秒、S6 压到 11 秒、S7 压到 8 秒、S9 压到 6 秒，总计约 61 秒。
**但 S3 和 S4 不能压**：S3 是差异点 ① 的唯一证据，S4 是差异点 ④ 的唯一证据，压缩时优先牺牲落版静置时间。
